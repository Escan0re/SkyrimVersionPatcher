При установке выбираются только три основных депо и одно соответствующее языковое; последнее применяется после основных, чтобы его `Skyrim_Default.ini` имел приоритет. Существующие настройки в `Documents/My Games/Skyrim Special Edition` получают точный `sLanguage` из проверенного выбранного `Skyrim_Default.ini` и имя соответствующего голосового архива. Традиционный китайский сохраняет английскую озвучку. INI изменяются без резервной копии; остальные настройки и архивы модов сохраняются. Неиспользуемые архивы других языков остаются на диске, но исключаются из голосовых ссылок INI. Режим `RuntimeOnly` сохраняет установленную локализацию.

Приложение использует встроенный каталог из `data/versions.json`, включённый при сборке. Чтобы уточнить манифесты, примечания или ссылки, измените этот исходный файл и пересоберите приложение. Поддерживаются только две указанные версии. Обновления по HTTPS и пользовательского каталога в интерфейсе нет.

`manifestId` записывается **строкой**: длинные ID нельзя безопасно передавать через JSON-числа в некоторых редакторах. `appId` должен оставаться `489830`, `schemaVersion` — `1`. Поле `sourceUrl` служит только справкой и автоматически не открывается. Повторы JSON-полей и версий запрещены.

## Проверенные хеши EXE

База `executable-hashes.json` отделена от каталога manifest ID. Для двух поддерживаемых версий в поставку пока не включены образцы, подтверждённые проверенной квитанцией depot-кэша и соответствующим манифестом Steam; список `executables` пуст.

Приложение читает Windows VersionInfo и вычисляет SHA256 установленного EXE. Один номер версии не объявляет файл официальным. Подходящий проверенный Steam-кэш может дополнить базу только в памяти текущего запуска.

## Переиспользование блоков и бинарные пакеты

Блоковые описания читаются из публичных незашифрованных манифестов Steam того же depot. Целевые SHA1 файлов и блоков используются для проверки локальных данных, включая блоки, которые переместились внутри BSA. Состав и размеры целевого depot должны быть полностью восстановимы, иначе запрашивается полное depot через Steam. Патчер не читает depot keys и не загружает отдельные недостающие CDN-блоки самостоятельно.

Готовые бинарные переходы между **1.6.1170** и **1.5.97** пока не включены: `transitions/index.json` содержит пустой список пакетов. Формат `.svpt` и его построитель — собственный код проекта. Пакеты не содержат выполняемых сценариев: только JSON-описание диапазонов, контрольные суммы и данные изменившихся диапазонов. Перед установкой собранные файлы проверяются в отдельной рабочей папке. Режим `RuntimeOnly` оставляет игровые данные и локализацию установленной копии; формат `Complete` сам по себе не доказывает полноту целевых depot.
